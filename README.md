# FAIRy Website

Website for **FAIRy** — a local-first dataset validation and readiness tool.

## About

FAIRy helps researchers, labs, and institutions validate and prepare datasets before submission. The tool runs locally on your computer and generates readiness reports with attestation files.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- React 19
